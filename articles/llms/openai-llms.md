Here's an overview of the current OpenAI LLM model names you can use:

GPT-5 Family (Flagship)
GPT-5 is OpenAI's current flagship general-purpose offering, with the latest version being GPT-5.4 (as of March 2026). It's also available as GPT-5.4 Pro, which uses more compute for consistently better answers. Additionally, there's GPT-5 mini (cost-sensitive, low-latency workloads) and GPT-5 nano (fastest and most affordable). IBM

GPT-4.1 Family
GPT-4.1 is OpenAI's smartest non-reasoning multimodal LLM — a general-purpose Swiss Army knife. GPT-4.1 mini is fast and affordable, performing close to GPT-4.1 at a fraction of the cost. GPT-4.1 nano is the smallest in the series. Zapier

Older / Legacy Models (still available via API)
These include gpt-4o, gpt-4o-mini, gpt-4-turbo, gpt-4, gpt-3.5-turbo, as well as audio variants like gpt-4o-audio-preview and gpt-4o-mini-audio-preview. Datasette

Reasoning (o-series) Models
The o-series includes o1, o1-preview, and older variants like o1-2024-12-17. Datasette

Open-Weight Models
OpenAI has released two open-weight models under an Apache 2.0 license: gpt-oss-120b and gpt-oss-20b, aimed at organizations that want to run models on their own infrastructure. Eesel AI

For the most up-to-date and complete list with pricing, I'd recommend checking OpenAI's official model documentation directly, as new models are released frequently.
